# GM Site

A modern static website project with HTML, CSS, and JavaScript.

## Structure
- `index.html`: Homepage
- `about.html`: About page
- `contact.html`: Contact page
- `assets/`: Contains images, styles, and scripts

## Setup
No build tools required. Simply open `index.html` in your browser to view the site.

## Customization
- Edit HTML files for content changes
- Update `assets/styles/style.css` for styles
- Add scripts to `assets/scripts/main.js`
- Place images in `assets/images/`
